# The-Last-Airbender-API
Descrição do Projeto

Este projeto consiste em uma aplicação backend desenvolvida em Python para consumir, processar e estruturar dados provenientes da The Last Airbender API (API pública do universo de Avatar).

A solução foi construída utilizando conceitos de Programação Orientada a Objetos (POO) e manipulação de requisições HTTP (GET). A aplicação permite buscar dados gerais de personagens, bem como realizar consultas filtradas por nome e afiliação, tratando as respostas recebidas em formato JSON e exibindo as informações de maneira estruturada.

Origem do Projeto: Desafio 7DaysOfCode.
